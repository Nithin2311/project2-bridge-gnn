The prevalence comparator scores every row with the development positive fraction, so its AUROC is 0.5 and its AUPRC equals the test positive rate. All-code boosting uses the broader diagnosis vocabulary, including symptom and status codes. The pooled MLP summarizes the GNN's feature sources without message passing and is the closest tabular comparison.
