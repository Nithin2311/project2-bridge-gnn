\subsection{Non-graph baselines}
We fit separate binary classifiers for the three primary targets on the same eligible patient landmarks as the GNNs. Features summarize diagnoses recorded through the index date, following the target-specific stable-core and ICD-10 chapter-block mask. The 1,095-day input window yields binary bags for the 496 graph categories (CODE) and a broader bag (ALL) that admits non-graph categories observed in at least ten development landmarks. DEMO contains age and recorded sex. UTIL contains diagnosis and visit counts, time since the first era diagnosis, and index year. BRIDGE contains the count of target-associated bridge flags and the sum and maximum of raw target-specific bridge scores. TEMP summarizes recency over retained graph codes. POOL concatenates the means and maxima of standardized static node columns and the GNN's per-code time features, over the same observed graph codes; an empty bag has zero pooled features.

The prevalence comparator predicts the refit's development positive fraction. L2 logistic regression uses CODE, DEMO and UTIL. Histogram gradient boosting and the first MLP add BRIDGE to those inputs. An all-code boosting model uses ALL, DEMO and UTIL. A pooled MLP uses CODE, DEMO, UTIL, TEMP, BRIDGE and POOL to summarize the GNN's feature sources without message passing. A second logistic regression uses BRIDGE, DEMO and UTIL to assess how much signal the bridge summaries carry alongside clinical covariates. Its inputs still include demographics and utilization, so the comparison does not attribute its entire discrimination to bridges.

Five patient-grouped folds over canonical training and validation patients select the configuration with the highest mean fold average precision. Single-class validation folds provide out-of-fold probabilities and are omitted from the tuning score. Logistic regression uses balanced class weights and searches \(C \in \{0.01,0.1,1\}\) with a 2,000-iteration cap. The balanced histogram booster searches learning rates \(0.03,0.1\), 15 or 31 maximum leaves, and 50, 100 or 300 boosting rounds. The MLPs use Adam with a learning rate of 0.001 and a batch size capped at 200, hidden widths \((64)\) or \((128,64)\), and L2 penalties \(10^{-4}\) or \(10^{-3}\). An inner patient-disjoint validation split selects the epoch by average precision with 20 epochs of patience and a 300-epoch cap. Each MLP refits on the entire development set for the median selected epoch count. Logistic and MLP scalers are fitted within each fit partition, with centering and unit-variance scaling. Initialization and the inner validation split use seeds 0--4. Each refitted model scores the unchanged canonical test set once. Deterministic fits share the same predictions across seeds when the development cohort is fixed. We report mean and standard deviation across seeds with seed-0 95\% percentile intervals from 1,000 patient bootstrap resamples. Average precision is the reported AUPRC.

Class-balanced fits shift every logit by \(\log(n_{\mathrm{neg}}/n_{\mathrm{pos}})\); we remove that shift at prediction, the same prior correction applied to the GNNs, so probabilities, Brier scores and calibration curves share the prevalence scale. Rankings, selection and AUPRC are unchanged by the correction. The shared Layer~U node statistics use full-era development records, so their temporal validity is assessed separately by the pre-2020 graph backtest.
